# DigiGate Integration for Home Assistant

Control your DigiGate system directly from Home Assistant using a custom `cover` entity.

## Features

- Open and close your gate
- Local control via IP + API code
- UI-based setup (no YAML required)

## Setup

1. Copy to `/config/custom_components/digigate/`
2. Restart Home Assistant
3. Go to **Settings → Devices & Services → Add Integration**
4. Select **DigiGate** and enter your IP + API Code
